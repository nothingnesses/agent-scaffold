### `reviewer-reproducible-evidence`: reviewer findings must carry reproducible evidence proportional to the claim (`Q-66`)

Next (built first, before resuming the paused `code-value-audit-static` step 86). Decided (`Q-66`, Socratic, human, 2026-07-26). Every reviewer finding must carry reproducible evidence PROPORTIONAL to its claim, so a finding is reproduced and adjudicated on its evidence rather than taken on the reviewer's word.

The rule (tiered reproducible evidence). For a BEHAVIORAL or correctness claim (a panic, non-determinism, a wrong output, or "this test is vacuous"), the reviewer provides a RUNNABLE demonstration; the strongest form is a MUTATION, to prove "test T does not really cover code C", break C and show T still passes (the pseudo-tested-method logic). For a DOC, DESIGN, or style claim (stale help text, an em-dash, a naming-collision risk), the reproducible evidence is an EXACT command (grep, diff, or build output) or a `file:line` citation, NOT a contrived test. The evidence is scaled to the claim, so the rule never forces a contrived test where a command or a citation already settles the point. The TRIAGER reproduces whatever the reviewer provided and DISMISSES any testable claim whose demonstration does not reproduce; when that dismissed claim is HIGH or CRITICAL, the dismissal still passes the existing second-triager backstop re-check (`pack/AGENTS.md:59`) before it counts toward a clean round, so the new dismissal ground composes with the backstop rather than bypassing it.

Files the implementer changes:

- `pack/prompts/reviewer.md`: the reviewer authors reproducible evidence proportional to its claim (a runnable or mutation demonstration for a behavioral or correctness claim; an exact command or a `file:line` citation for a doc, design, or style claim), run in the reviewer's own isolated worktree, which every spawned agent already gets under the uniform-isolation rule.
- `pack/prompts/triager.md`: the triager reproduces the provided evidence and dismisses any testable claim whose demonstration does not reproduce.
- `pack/AGENTS.md`: fold the rule into the Reviewers and Triager role bullets and/or the Findings files section, so the guidance and the prompts state one rule.
- Deployed copies (documentation currency): `just scaffold-self` re-renders the root `AGENTS.md`, `.agents/AGENTS.reference.md`, `.agents/prompts/reviewer.md`, and `.agents/prompts/triager.md` from the edited pack, then runs `nix fmt`. The whole-file AGENTS.md drift guard (`agents-md-drift-guard`, step 80) fails if the committed `AGENTS.md` and its `.agents` copy are not a fresh render of the edited `pack/AGENTS.md`, so the regeneration is required, not optional.

The deterministic checks reviewer already reports every finding with the strongest evidence tier, the check name, the exact command, its exit code, and the offending `file:line`, so it already complies with (indeed exceeds) the tiered rule; the `reviewer.md` + `triager.md` + `pack/AGENTS.md` file set is intentional, not an omission.

The mutation demonstration is the same pseudo-tested-method mechanism the reserved `Kind::Mutation` variant (`src/checks.rs:94-95`) and the deferred `code-value-audit-deletion-experiment` step 87 build on, reusing `checks`'s isolated-worktree machinery; a reviewer runs the demonstration by hand today in its own worktree, and step 87, once its evidence gate opens, is the tool-side automation of the same idea. This step is prompt-and-guidance only: it does NOT build the mutation module or touch `src/checks.rs`, which stays step 87's territory.

Principle grounding (by name). The requirement makes findings falsifiable and checkable, which is Ground decisions in evidence (plan Principle 6) and Reproducible (plan Principle 7, evidence a second party can re-run) applied to the review loop; it is the AGENTS.md workflow guidance "Verify, don't trust" and "Cite sources rather than asserting from memory" made concrete for reviewers, and "Tests must actually exercise the code they claim to" made enforceable through the mutation demonstration. The counterweight is Minimal by default (plan Principle 2): the evidence is proportional, not maximal, so a doc or style claim carries a command or a citation and never a contrived test.

Chosen over a runnable test for EVERY finding (rejected: forces contrived tests for doc and style claims), over a triager-enforced reviewer-SHOULD (rejected: leaves the evidence optional, so a bare assertion can still stand), and over keeping the current process (rejected: a finding can be taken on the reviewer's word).
